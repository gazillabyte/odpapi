# Community adapter projects

ODPAPI is intended to make integrations portable across data-protection
systems. Independent adapters may be open source or proprietary; Apache-2.0
licensing of the ODPAPI project does not require adapter authors to publish
their source.

Adapter maintainers who want their project advertised can open an **Adapter
project listing** issue in the ODPAPI GitHub repository. Include the public
project URL, maintainer name, protocol version, supported operations,
platforms, license, and an optional public support link. Submit only
information approved for public redistribution.

A listing is informational and is not certification, endorsement, or a support
commitment. Maintainers may request corrections or removal.

There are no community listings yet. See [`ECOSYSTEM.md` in the source
repository](https://github.com/gazillabyte/odpapi/blob/main/ECOSYSTEM.md) for
the listing process.
