# Contributing

Contributions to ODPAPI project-owned materials are welcome. Before opening a
pull request, check the current `README.md`, `ADAPTER-CONTRACT.md`, and
`AGENTS.md` for scope, compatibility, and security guidance.

By intentionally submitting a contribution for inclusion, you agree that it
is offered under Apache License 2.0, as described by section 5 of that
license, unless you clearly identify different terms before submission. Do not
submit code or documentation you do not have the right to contribute. A
separate contributor agreement is not currently required by this repository.

For protocol changes, include the motivation, affected operation(s), request
and response examples using synthetic data, compatibility/versioning impact,
and verification evidence. For C helper changes, update the Doxygen comments
and validate the CMake build; run the `odpapi-docs` target when Doxygen is
available.

For an independently developed adapter, use the process in `ECOSYSTEM.md` to
request a project listing. Please do not submit proprietary adapter source,
credentials, or customer payloads to this repository.
